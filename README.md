NusaStat is an offline-first national statistics portal for the Republic of Indonesia featuring interactive macroeconomic, demographic, and regional indicators, custom SVG visualizations, provincial comparisons, and CSV/JSON data exports.

## Run it

```sh
node serve.ts
```

To build the static output bundle and `dossier.json`:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
